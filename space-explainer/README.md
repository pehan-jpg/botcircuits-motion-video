# space-explainer

Remotion project for the "Space by BotCircuits" explainer (1920x1080, 60 fps, 2:02).
Rules, story and commands: see [DESIGN.md](DESIGN.md).

Built so far: Scenes 1 to 3. The deliverable is `out/space_video.mp4` (`npm run render:video`).

Renders use a local Chromium when `/opt/pw-browsers/...` exists or `REMOTION_BROWSER` is set.

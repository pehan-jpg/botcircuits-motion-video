# Third party logos: sources

All files are used unmodified (no recolour, no redraw). Each is a **third party
copy** downloaded from Wikimedia Commons, not from the brand owner's own media
kit, because the build environment's network policy blocks the official hosts
(`www.gstatic.com`, `ssl.gstatic.com`, `slack.com`, `a.slack-edge.com`
returned proxy 403). **Flag: verify each against the official artwork before
release**:

- Google products: Google brand resource center, https://about.google/brand-resource-center/
  and the Google Workspace brand guidelines.
- Slack: Slack media kit, https://slack.com/media-kit

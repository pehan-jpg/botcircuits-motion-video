# botcircuits-motion-video

Remotion project for BotCircuits product motion videos.

## PaymentsUseCase

A 26 second, silent, vertical (1080 x 1920, 60 fps) video: an AI agent pays a
supplier invoice inside a WhatsApp style chat, then handles four related
payment scenarios (status, bulk, duplicate, scheduled).

All copy, names, amounts and timings (in seconds) live in `src/content.ts`.
Design tokens and easings live in `src/theme.ts`.

```bash
npm i
npx remotion studio
```

Render:

```bash
npx remotion render src/index.ts PaymentsUseCase out/payments-usecase.mp4 --muted --codec h264 --crf 16
```

Review stills (bundles once, renders any frames):

```bash
node scripts/stills.mjs out/stills 60 300 880
scripts/contact-sheet.sh out/stills out/sheet.png 5
```

### Layout

| Path | Purpose |
|---|---|
| `src/content.ts` | Copy, placeholders, scene and camera timings |
| `src/PaymentsUseCase.tsx` | Virtual camera, phone depth, screen slides, motion blur windows |
| `src/components/WhatsAppChat.tsx` | Reusable WhatsApp style chat and message parts |
| `src/components/PaymentRoute.tsx` | Payment route, stepper and Paid chip |
| `src/components/Background.tsx` | Flowing mesh gradient and film grain |
| `src/scenes/` | Main conversation, scenarios, closing |

### Notes

1. Inter (SIL Open Font License) is bundled in `public/fonts` so renders work offline.
2. The closing uses a placeholder wordmark. Add `public/botcircuits-logo.svg` and
   swap it in `src/scenes/Closing.tsx` (see the TODO there).
3. `public/grain.png` is generated by `node scripts/make-grain.mjs`.
